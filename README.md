# 빈 앱

아무것도 없는 앱에서 시작해서, 유튜브 댓글로 고른 기능을 하나씩 추가하는 프로젝트입니다.

## 파일 구조

- `index.html` — 화면 뼈대
- `style.css` — 디자인
- `script.js` — 기능 (에피소드별로 주석 구분)
- `CHANGELOG.md` — 에피소드별로 추가된 기능 기록

## 배포 (GitHub Pages)

1. GitHub에서 새 저장소를 만들고 이 파일들을 올립니다.
2. 저장소 **Settings → Pages**로 이동합니다.
3. Source를 **Deploy from a branch**, 브랜치를 `main` / `/(root)`로 선택하고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속됩니다.

이후에는 파일을 수정해서 push하면 자동으로 반영됩니다.

## 진행 규칙

- 기능은 유튜브 댓글 중에서 직접 고릅니다.
- 한 번에 기능 하나만 추가합니다.
- 추가할 때마다 `CHANGELOG.md`에 기록합니다.
